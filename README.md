# Aeris — сборки

Здесь лежат только готовые сборки для автообновления.

| Платформа | Файл |
| --- | --- |
| Windows, установщик | `Aeris-Setup-<версия>.exe` |
| Windows, портативная | `Aeris-Portable-<версия>.exe` |
| Android | `Aeris-<версия>.apk` |

Установленное приложение обновляется само: проверяет релизы здесь, скачивает
новую версию в фоне и предлагает перезапуск. Скачивать руками нужно только
в первый раз.

## Почему репозиторий публичный

`electron-updater` ходит к приватному репозиторию только с токеном, а зашивать
токен в приложение, которое раздаётся людям, нельзя. Поэтому публичен именно
этот репозиторий — в нём нет ни исходников, ни секретов.

Исходный код лежит в приватных репозиториях: `aeris-web`, `aeris-desktop`,
`aeris-android`, `aeris-ios`.

## Установка

**Windows.** Скачайте `Aeris-Setup-<версия>.exe`. Пакет не подписан, поэтому
SmartScreen покажет предупреждение: «Подробнее» → «Выполнить в любом случае».

**Android.** Скачайте `.apk` и разрешите установку из неизвестных источников.
